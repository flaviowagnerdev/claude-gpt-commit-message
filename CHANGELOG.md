# Changelog

## 1.2.1

- Correção: textos de introdução que a IA escreve antes da mensagem (ex.: "Using the commit-message format…") agora são descartados; a mensagem começa sempre no cabeçalho tipo(escopo): descrição.
- GIFs e prints da documentação regravados com o nome novo.

## 1.2.0

- Novo nome: **AI Commit Message (Claude/GPT)**.
- Categoria do Marketplace alterada para "AI".
- README com instruções de instalação pelo Marketplace e aviso de marcas.
- Pacote menor: GIFs e prints da documentação não vão mais dentro da extensão.

## 1.1.0

- Página da extensão com GIFs de funcionamento e prints da configuração.
- Autoria: desenvolvido por Flávio Wagner.
- Botões secundários da tela de configurações com borda, visíveis em qualquer tema.

## 1.0.1

- Mensagens de commit sempre em português do Brasil (Conventional Commits).

## 1.0.0

- Primeira versão: botão no Source Control que gera a mensagem de commit pelo Claude Code CLI ou pelo Codex CLI (GPT), sem chave de API.
- Tela de configurações: IA, modelo, máximo de tokens da resposta e do diff, tempo máximo e system prompt editável.
- Remoção de crases e de linhas de introdução da resposta.
